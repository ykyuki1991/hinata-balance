# v3 プレイ検証

## 評価の要点

- 序盤：四方から来る小さな申請で移動・自動照準が成立。次の遭遇で至急の直線予告、その次で催促の射線が加わる。静止は約27秒で失敗し、単なる左右往復も突破しない。
- 中盤：設備の裏側では自動照準が通らず、回り込む理由がある。回覧元を放置すると追尾敵が増える。再申請は1.3秒の出現予告を持ち、即時接触にはならない。
- 終盤：外側の締切帯と保留の環状弾により、画面周辺を回るだけの方針を崩す。予告の向きはロックされ、後からプレイヤーを追わない。
- ボス：突進後の停止、二つの中継器、3段階決裁という別々の攻略。最終ボスを火力で短時間に飛ばす問題を段階移行で修正。段階の閉鎖中はダメージを受けない。
- リスクと報酬：接近して倒すと基本点1.5倍。印を取りに移動すると倍率付き得点、射撃強化、差戻し再充填。画面外から自動回収する設計にはしない。
- 入力：タッチの終了と結果表示が重なるクリック抜けを実際のChromeタッチ入力で検出・修正。切替前から継続中のジェスチャーによるクリックのみを遮断する。
- 演出：通知は戦闘床の外側へ。ボスの色以外にシルエットと段階表示も区別。横向きはアリーナの縦横比を保持し、操作欄を横へ配置。

## ローカル結果

29件の単体・シミュレーションテスト、lint、TypeScript検査、Vite本番ビルドが成功。親PWAは37件のプリキャッシュを維持し、ゲームは対象外。

最終シミュレーションは48走行。静止・往復・一定円運動は通常/繁忙日とも0/6クリア。戦術入力は各6/6。戦術コントローラは人間より正確なので、これは初見難易度の推定値ではない。

最終のChromeタッチ走行は106.7秒・3被弾・101,680点でクリア。マウス走行105.9秒・1被弾、横向きWebKit走行98.6秒・1被弾。いずれもゲームオーバー・再挑戦・記録再読み込みまで確認。詳細は各JSON。

PC1280×720、iPhone相当390×844、小型320×568、横向き750×342をChrome/WebKitで確認。ボタンが画面内に収まり、横スクロールなし。実時計の描画計測は開発用Mac上でChrome p95約0.4ms、WebKit約1ms（14秒、300サンプル）。実機iPhoneの処理速度を測った値ではない。

公開版の検証結果は`shonin-v3-public-*.json`とリリース記録へ追記する。実機iPhoneを接続した検証は実施していない。ChromeのネイティブタッチとWebKitのPointerEvent経路・ネイティブタップを区別して記録する。
