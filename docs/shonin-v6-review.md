# v6 プレイ評価

## 変更の根拠

v5は判断を増やした際に移動・照準・射撃解除・能力を指へ積み重ねてしまった。v6は片指の相対移動を中心にし、自動射撃が選ぶ対象を近い列として可視化。自動で至急を優先せず、どの列へ移るかをプレイヤーへ残した。

## 初回30秒

単一タッチだけの約29秒試作で5件の処理、差戻し2件、再申請2件、単線分岐を通過。照準・射撃・チャージ入力なし。初回は通常書類、差戻し、その後に至急を重ねて、最初から全機構を出さない。下の相対操作領域から自機を動かし、案件へ指を重ねなくてよい。

## 中盤・終盤

並行は2つの承認を保存して合流する。v5の短い同時破壊窓をなくし、未完了側の催促と他案件の期限を比較する。最終章では決裁後の待ち列が複数送り先に生まれ、送り先と新着のどちらを先に処理するかが変わる。通知は敵ではなく流れていく。保留は一件だけを時間ごと退避させ、特殊操作を使わないクリアも成立する。

## 調整で直した点

新着書類と送り先アイコンが重なっていたため、最終章の書類到着位置を下げて分離した。差戻しの待ち時間に至急が来るよう到着間隔を調整した。中盤以降は普通の案件と至急が同時に届く短いまとまりを入れ、処理順の問いを作った。送信待ち列にも催促を加え、放置すればよい対象にしない。出現列はシードで変える。

## バランスと限界

48条件の入力シミュレーションで単純な左右往復、優先順位を判断する移動の両方がクリア。判断戦略の平均得点は各条件で上回った。簡単な移動で入口を作り、判断の効果を得点と待ち時間に移す狙いに合う。ただし自動操作は内部座標が分かるため、人間の片手操作や面白さを保証するものではない。

25テスト、lint、TypeScript、本番ビルドを通過。ローカルChrome／WebKitの縦・横・小型画面で、全章クリア、保留／再開、ゲームオーバー、リトライ、保存を確認。描画性能はMac上の14秒の実時間サンプルで測定。物理iPhoneは未使用。公開版の最終結果はrelease記録とpublic JSON群へ保存する。
