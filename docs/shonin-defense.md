# 承認防衛線 — RE:WORK（v2.0.0）

公開URLは維持: https://ykyuki1991.github.io/hinata-balance/shonin-defense/

朝の受付から月末の夜まで、約2〜3分・3ステージのお仕事シューティング。スライド／マウス／左右キーで移動、自動射撃、ボタン／Spaceで一括否認。機体の中心が当たり判定です。音は初期OFF、ONにすると各ステージとボスに合わせたオリジナルの短い曲と効果音を再生します。P／Escape／Ⅱで一時停止、画面を離れると自動停止します。

## 3つの現場

| 現場 | 道中で学ぶこと | ボスの攻略 |
|---|---|---|
| 09:00 朝の受付 | 横列・V字の全件承認、至急の狙い弾を予告で避ける | 回覧ルート：左右の承認印を壊すと中央の決裁が開く |
| 14:00 回覧経路 | 発射前に回覧を止める、左右を変えて再申請する差戻しを追う | 差戻しループ：確認中の閉鎖と受付中の弱点、列攻撃・弾幕のすき間 |
| 17:55 月末の夜 | 混合編隊の優先順位、一括否認の残量管理 | 月末締め：集計中は回避、最終決裁中は攻撃。移る安全なすき間、狙った列の締切レーザー、扇形弾 |

各ステージは約27.5秒の道中→ボス→2.4秒の処理完了演出。ステージ1と2のクリア後にライフ1回復と装備選択。最大4ライフ、未処理通過は3件で1ライフ損失。ボスには画面に表示する55秒の締切があり、無限に停滞しません。最長では約4分強、習熟したプレイは約2分10秒〜2分30秒です。

## 選択とスコア

- 1回目の装備選択：広い3方向射撃の「並列承認」／細い貫通射撃の「直列決裁」。
- 2回目：「代理承認」で1回被弾を肩代わり／「即時決裁」で一括否認の再充填を加速。
- コーヒーは7秒の射撃加速＋3方向弾、権限アイテムは再充填35%。被弾しても恒久装備は失いません。
- 3.5秒以内の連続処理でコンボ、10件ごとに倍率が上がり最大5倍。被弾はコンボ半減、申請を通すとコンボ切れ。
- 編隊全機を通常射撃で処理すると「全件承認」ボーナス。一括否認の敵得点は半分・コンボ増加なし・編隊ボーナスなし。その代わり敵弾を消して得点にし、短い無敵を得ます。否認で即座に次の否認を充填できません。
- 弾をぎりぎり避けると権限が再充填。1つの弾からは1回だけ、同じ弾を往復して稼げません。
- 終了時にS〜D評価、処理件数、全件承認、被弾、所要時間、突破した現場を表示。クリア・無傷・40コンボ・全件承認8回・繁忙日突破の5実績。
- リトライは同じ編隊順。タイトルに戻って出勤すると別の順番になります。序盤2編隊は常に基本操作を学べる構成です。
- 繁忙日はボスの攻撃間隔短縮、回覧の扇形拡張、最終ボスの複合攻撃。敵HPを増やすだけのモードにはしていません。

## ビジュアル・実装

外部フォント・画像配信・音声ファイル・ゲームライブラリ不要。3枚のオリジナルSVG背景と、Canvasの機体・紙の敵・ボス・予告・弾・スタンプ・粒子で描画します。背景は受付の街並み、回覧ネットワーク、夜景と書類棚。Web Audioの発音数、粒子数、敵弾数を制限し、端末のDPRは2まで。画面サイズが変わっても480×720の内部座標と当たり判定は同一です。

`engine.js` が純粋なゲーム進行、`render.js` が描画、`audio.js` が音、`game.js` が入力・UI・保存を担当。古いService Workerやブラウザキャッシュとの混在を避けるためモジュール・CSSにはバージョンを付けて読み込みます。旧版記録は削除せず、新ルールの記録を別のlocalStorageキーに保存します。記録の外部送信はありません。

実在の人物、社内ルール、申請データ、内部情報、POWER EGGの画面やロゴは使用していません。完全に架空の世界の非公式ゲームです。

## 検証

- `npm test`：既存ゲームを含む30件。射線の予告と発射、当たり判定、無敵と代理、差戻し、全件承認、一括否認の制約、各ボス、装備選択、期限、クリアを検証。
- `npm run lint` / `npm run build`：既存Pagesフローで実行。
- `node scripts/shonin-sim.mjs`：2モード×4戦略×6編隊種のバランス比較。勝率は自動操作の比較値であり、人間のクリア率ではありません。
- `node scripts/shonin-browser-check.mjs`：公開UIからの移動・タッチ・装備選択・全3ステージ／ボス／クリア・リトライ・自然なゲームオーバー。`SCENARIO=desktop|iphone|small-phone|landscape`、`ENGINES=chromium|webkit`で指定。
- `node scripts/shonin-layout-check.mjs`：1280×720、390×844、320×568、750×342のChrome/WebKit、画面回転とキーボード操作。
- `node scripts/shonin-performance-check.mjs`：時刻を加速しない実時間のプレイと描画処理時間。
- `node scripts/shonin-public-check.mjs`：公開10ファイルとローカルの一致、既存ゲームのService Workerとの共存、通常URLに診断が出ないこと。

`GAME_URL`で公開URLを指定できます。ローカルVite開発サーバーでは `/shonin-defense/index.html` を指定。`PLAYWRIGHT_BROWSERS_PATH`でWebKitの保存先を指定します。`?qa=1`の診断は読み取り専用で、ライフ増加、ステージ移動、無敵、スコア書き換えの機能はありません。テストは実際の入力を通し、ゲーム状態を直接進めません。

最終結果は `docs/shonin-v2-public-*.json`。`local` は開発中の各改善段階の記録です。加速時計を使用したテストの処理時間は採用せず、実時間の `performance` 結果を参照します。iPhone相当のタッチ／画面サイズ／WebKitを検証し、iPhone実機は使用していません。
