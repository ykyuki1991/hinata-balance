# 承認防衛線 — 未処理、接近中。

v5.0.0。公開URL: https://ykyuki1991.github.io/hinata-balance/shonin-defense/

## 操作と判断

スマホは左で移動、右で照準・射撃。PCはWASDで移動、マウスで狙って押して撃つ。矢印はキーボード照準。射撃を離すと1.1秒でチャージし、次の弾が装甲を貫く。自動照準と通常弾の自動弾消しは廃止。

「承認」は60消費の方向指定貫通連射、「保留」は35消費の短い防御と押印弾の反射。Space／Shiftにも対応。同じゲージを直行ルートの60消費にも使う。保留中は射撃できない。

## コースと敵

進行距離による3章。前へ出るとスクロールが速く、下がると準備時間を取れる。棚とシャッターは移動と射線を遮り、敵弾から隠れる場所にもなる。破壊できる棚は強化射撃で開通できる。

装甲はチャージか裏側から攻撃。発生源は従属書類を守り、破壊すると従属書類は無得点で処理される。先に従属書類を貫いて得点を取る選択と競合する。添付爆弾は0.65秒予告して周囲に影響する。敵同士の連鎖は得点になるが自機も巻き込まれる。逆流紙には背後の照準が必要。

最初に貫通／拡散を接触で選び、次に直行／迂回を選ぶ。直行はコスト、敵構成、進行速度、得点倍率が変わる。迂回は遮蔽物と1回復。長い装備選択画面を挟まない。

ボスは、装甲に対する回り込み・チャージ、二機関の残量調整と同時停止、押印弾の反射による決裁口の開放。それぞれ異なる行動を要求する。最後は開放中に攻撃へゲージを使うか次の保留へ残すかを選ぶ。

## 文言・表現

「業務開始」「承認」「保留」「貫通／拡散」「直行／迂回」を中心に短く整理。プレイ中の常設説明はなし。最終ボスの初出時のみ「保留で返す」を表示。書類・押印・接続・分岐・後続への引き渡しは公式公開情報からの着想。反射や同期時間などは独自のゲームルールで、実際のPOWER EGG操作を再現するものではない。

## 実装と検証

`engine.js` はDOM非依存の固定刻みシミュレーション、`game.js` は入力・保存・キャッシュ移行、`render.js` はオリジナルの紙と機械の描画、`audio.js` はWeb Audio。既存Viteの `public/shonin-defense/` を静的コピーする。親ゲームの資産とPWA設定は変更しない。

保存先は `shonin-defense-v5`。旧版の保存値は残すが、異なるルールの得点を混ぜない。通常URLには診断APIなし。`?qa=1` のスナップショットは読み取り専用。

`shonin-browser-check.mjs` はゲーム状態を書き換えず実入力で全コース・分岐・ボス・死亡・クリア・再挑戦・保存を通す。ChromeはネイティブCDPの左右同時タッチ、WebKitは左右PointerEventとネイティブアクションタップ。物理iPhoneは未使用。

設計は `shonin-v5-design.md`、比較は `shonin-v5-balance.json`、公開後の証拠は `shonin-v5-public-*`。
