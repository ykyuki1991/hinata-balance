# 承認防衛線 v4 — FLOW BREAKER

2026-09-06。実装前の調査・設計。公式の公開資料のみを利用する。以下のゲーム化は独自の比喩であり、製品の操作・権限を再現するものではない。

## 調査から得た構造

- NaviViewは個人に関係する情報の入口。未読の情報と、処理を要する案件を同一視しない。ゲームでは背景の通知灯と、前景で対処する書類を区別する。[基本編](https://poweregg.d-circle.com/support/members/assets/manuals/PE350c_UsersManual_01Base.pdf)、[通知の既読](https://poweregg.d-circle.com/faq/001742/)。
- 汎用申請は帳票とルートの組合せ。入力値によるルート選択と、並行して進む枝は別物。[設定概要](https://manualv35c.poweregg.net/users-rrd-setting/3.5c/01overview/02setting)。
- 審議は途中の判断、決裁は最終判断。回覧は確認して次へ渡す役割、同報は情報共有、受付は確認・差戻しやルートの調整を担う。合議の意見と否認によるフロー停止は同じではない。条件付決裁は条件を付した判断であり、条件分岐ではない。[利用概要](https://manualv35c.poweregg.net/users-rrd-use/3.5c/01overview/00chapter)。
- 並行審議は全員の承認を待つ。グループ1名は誰か1名の処理で進む。ルートの分岐・合流は複数の枝の完了を待つ。ゲームでは両ノードを壊すANDゲートと、片方を選ぶORゲートを形で分ける。[ルート設定](https://manualv35c.poweregg.net/users-rrd-setting/3.5c/02setting/03application-04)。
- 差戻しは先へ流れた案件を前段へ戻す。引き戻しは後続がまだ処理していない承認を本人が戻す操作。取下げは申請者側の操作。この3つを一つの攻撃名に混ぜない。[引き戻し](https://manualv35c.poweregg.net/smartphone/3.5c/11fap/08search)、[フロー操作](https://manualv35c.poweregg.net/users-rrd-use/3.5c/04wf/00chapter)。
- 後閲は条件・権限の下で途中の審議を先へ進める機能。決裁者を飛ばす無制限の近道ではない。ゲームには実装せず、誤った近道ボーナスにしない。[後閲](https://manualv35c.poweregg.net/smartphone/3.5c/11fap/03approval-reference)。
- 代理申請は他の申請者のための起案、代行は審議・決裁の担当を引き受けること。ゲームでは仲間の小型押印機が並走し射撃を手伝う比喩に留める。[代行](https://manualv35c.poweregg.net/admin/3.5c/06wf/02root-06)。
- 決裁後も仕事は続く。Web DBへの記録、掲示板への共有、ファイル管理への保存に渡せる。決裁時とフロー完了時は区別される。[連携](https://poweregg.d-circle.com/product/apps/workflow/feature/)、[連携時点](https://poweregg.d-circle.com/faq/000595/)、[ファイル連携](https://poweregg.d-circle.com/faq/001770/)。この下流への変換を最後の場面とクリア演出にする。

## v3の問題

全方位の追尾敵、近距離を要求する自動照準、回避ダッシュ、弾幕、無敵時間の長いボスが逃げ回る比重を高めた。四方の敵・予告・地形・落とし物に視線が散る。HUD、ステージ列、現場表示、装備、コンボ説明、操作説明、外枠ヘッダー・フッターが常設。スマホ縦画面の約3分の1がフィールド以外。敵とボスに文字を貼る比率が高い。

## 選定

横スクロールを採用。進行方向を右に固定し、敵を前方に整理。自動連射を続けながら上下位置で攻撃対象を選ぶ。スマホ縦も強制回転・レターボックスなし。縦横比に合わせ世界の横幅を変更し、同じ編隊を比率配置する。敵の接近時間は画面幅に合わせる。

3章、目標2〜3分。①通知が集まる受付：紙の列と発生源を撃ち抜く。②分岐審議：片方を選ぶ経路と両方を開ける合流、逆流する書類。③決裁・連携：決裁装置を部位から崩し、処理済み書類がデータ・保存ファイル・共有へ流れる。

通常弾でも催促弾を消せる。敵を早く倒せば発射を止められる。攻めてゲージを回復し、任意のタイミングで貫通する「一括承認」を放つ。被弾回避だけでは得点・火力が伸びない。ボスは常に攻略可能な部位を持ち、待つだけの無敵フェーズを廃止。早い処理、連続処理、ルート選択が得点差になる。

## 美術・UI

紙と精密機械の架空の郵送工場。濃いインク色、生成りの紙、朱の敵機関、青磁の承認エネルギー。書類の折り・留め金・添付クリップ、機械の関節と発光窓で敵の役割を描く。背景は線路・機関・棚の低コントラスト3層。承認印は処理後だけ。未読の背景灯を危険弾の色形と分ける。

画面全体をフィールド。上端にライフ・得点・音・一時停止。右下にゲージを兼ねたアクションボタン。章名とボス名は短い登場時だけ。開始画面の操作は1行。装備選択の中断画面は廃止し、拾った分だけ随伴機を増やす。結果はランク・得点・記録・再挑戦に絞る。実在のUI、ロゴ、社員、社内データを使わない。
