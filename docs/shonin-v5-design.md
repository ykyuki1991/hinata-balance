# v5 — プレイヤーの判断を取り戻す

## 実装前のv4分析

代表的な8秒を1秒ずつ見る。0秒：近い敵を選ぶ。1秒：そのYへ移動。2秒：同じ高さで待つ。3秒：自動射撃で倒れる。4秒：次の敵のYへ移動。5秒：満タンなら一括承認。6秒：撃ち続ける。7秒：次のYを選ぶ。source優先という重みを変えても、このループの意味は変わらない。

照準補正は最後の狙いを、通常弾の弾消しは防御を、撃破数による強化は成長をゲーム側が代行している。貫通連射には消費先の競合がなく、早期処理が得点・安全・成長を同時に満たす。分岐の後の変更は小さく、背景の経路は通行を制限しない。3ボスとも部位を消して本体を撃つだけ。単純な検証プレイヤーの安定クリアは、この判断の少なさを表す。

## コアループ

移動と照準を分離する。スマホは左側ドラッグで移動、右側ドラッグで射撃方向。PCはWASDとマウス押下、矢印で照準するキーボード単独操作も用意。自動照準を廃止。射撃を離すとチャージ、次の射撃が装甲を貫く。通常弾の自動弾消しは廃止する。

共有ゲージを攻撃60、防御35、上級ルートへの進入60で取り合う。攻撃は狙った方向に貫通射撃、防御は短時間の保留フィールド。タイミングを合わせると押印弾を送り返す。防御中は発射を停止するため、攻撃と同時に最大利益を取れない。

## 敵・空間・選択

普通の書類は狙って処理。装甲は正面を防ぐため、溜めるか回り込む。発生源は従属書類を守り、倒すと一掃できるが従属書類個々の高得点を失う。添付爆弾は少し遅れて周囲へ影響し、早く安全に処理するか敵を巻き込むまで待つかを選ぶ。逆流紙は背後への照準を要求する。

スクロール距離でコースを進む。前へ出ると進行が速まり、後退すると準備時間を取れる。棚が射線と移動を遮り、敵弾からの遮蔽物にもなる。開閉する経路は待って溜めるか、別の道へ回る。破壊できる棚はゲージを使って突破できる。

最初の分岐で貫通／拡散を実物のアイテムで選択。次の分岐でコストを払う「直行」経路か無料の「迂回」経路を選び、その後の敵編成・遮蔽物・報酬を変える。専用の長い選択画面は設けない。

## ボス・テンポ

受付：正面装甲に対しチャージで崩すか裏へ回る。回覧機関：2つの機関の残量を調整し、片方が再起動する前に両方を停止する。月末締め：押印弾を保留で送り返して決裁口を開く。初期案では攻撃ゲージでも開けたが、常時攻撃で押し切れたため廃止。反射で開いた後、攻撃に使うか次の保留へ残すかを選ぶ。

快調な紙列 → 単独の新要素 → 分岐で選択 → 遮蔽物との組合せ → 短い解放 → ボス。章ごとに長さと配置を変え、5編隊の繰り返しを廃止。意味のないランダム化ではなく、ルート・シードで事前設計した組合せを変える。

## POWER EGG・文言・視覚

公式公開情報の調査は [v4設計](shonin-v4-design.md) を継承。並行処理や後続業務への引き渡しをルールの着想源とするが、時間制限や反射は独自のゲーム表現。実際の審議権限・操作の説明や再現ではない。

「業務開始」「承認」「保留」「未処理、持ち越し。」「本日の業務、完了。」を基本語彙にする。冗長な英語スローガン、造語の技名、説明の重複を避ける。ルート上の強化だけ「貫通」「拡散」の短い文字と射線アイコンを併用。敵の説明文は表示せず、装甲面、保護の接続線、爆発の予告円、機関の残量で読み取れるようにする。フィールド100%を維持。

## 評価方法

v4型の高さ合わせ＋連射＋強敵でゲージ使用を、入力APIだけ新方式に適合させて基準とする。失敗を射撃操作の変更だけで作らない。狙い・溜め・回り込み・残量調整・反射を行うプレイヤーとの差を評価し、状況ごとの選択をログに残す。両分岐と両武器、全ボス、死亡・再挑戦を実ブラウザで確認する。
