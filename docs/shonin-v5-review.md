# v5 検証と調整

序盤は紙列で移動と照準、装甲で射撃を離すチャージを導入。中盤は実際に移動・弾を遮る棚と開閉扉、武器と経路の接触選択。終盤は回覧の残量調整と押印弾の反射を要求する。3章は背景色だけでなく、通れる場所と必要な行動が変わる。

受付ゲートはチャージまたは回り込み、回覧機関は2機の同期停止、月末締めは保留で押印弾を返した後の攻撃が攻略となる。共有ゲージは承認60、保留35、直行60で競合する。連鎖爆発は予告円と遅延を持たせ、自機にも危険がある。棚に挟まれた際の連続被弾を修正し、最寄りの空いた縁へ分離する。

文言は業務開始、承認、保留、直行、迂回、もう一度を採用。終了は「本日の業務、完了。」「未処理、持ち越し。」。装飾用の英語見出しの重複を削り、最終ボスの初回だけ「保留で返す」を表示する。

26件の単体テスト、lint、TypeScript、本番ビルドを通過。48条件のシミュレーションでは高さ合わせ＋連射の基準戦略は0/24、状況対応戦略は24/24、対応戦略は平均約127〜135秒。これは行動差を確かめる補助であり、人間の初見難易度や面白さの証明ではない。検証操作は内部座標を読めるため、実際のプレイヤーより有利である。

ブラウザ検証はPCのキーとマウス、Chromeの複数タッチ、WebKitのポインター入力を使用。全章・ボス・クリア・自然な無操作死亡・再挑戦・記録保存と画面回転を確認する。ローカルの一部記録は調整途中なので、最終判定には公開版の記録を用いる。iPhone実機は未確認。描画性能測定もMac上のブラウザによるものである。
